# Smart-Gadget-Marketplace-Web-Application

# Overview

Smart Gadget Marketplace is a web-based e-commerce application developed to connect sellers and customers on a single platform. Sellers can list and manage smart gadgets, while customers can browse products, add items to their cart, and place orders securely.

# Features

Customer

- User registration and login
- Browse smart gadgets
- Search and filter products
- View product details
- Add products to cart
- Place orders
- View order history

Seller

- Seller registration and login
- Add new products
- Update product information
- Delete products
- Manage product inventory
- View customer orders

Admin

- Manage users
- Manage sellers
- Monitor products
- Manage customer orders
- Maintain the marketplace
